# 엑셀 정리기

**쓰기 전에**

1. 파일은 브라우저를 떠나지 않습니다. 읽기와 계산이 모두 이 브라우저 안에서 일어나며, F12 → Network 에서 파일 내용이 나가지 않는 것을 직접 확인할 수 있습니다. (나가는 요청은 `rules/<파일 이름>.json` 읽기뿐입니다.)
2. 이 정리기가 못 하는 것: 음수 교통비와 비정상적으로 큰 박수(예: 30)는 잡지 못합니다. 빈칸·연도가 두 자리인 날짜·큰 금액·«박수 0인데 숙박비 있음»은 고치지 않고 `_표시` 칸에 표시만 하므로 사람이 확인해야 합니다.
3. 처방은 `rules/` 의 파일을 고쳐서 바꿉니다. 코드(`clean.js`, `app.js`)에는 처방이 없습니다.

## 쓰는 법

엑셀(.xlsx) 또는 CSV 를 끌어다 놓으면 `rules/<파일 이름>.json` 의 처방대로 정리본과 바꾼 기록이 나옵니다. 맞는 처방 파일이 없으면 직접 골라 올릴 수 있습니다.

내 컴퓨터에서 열 때는 이 폴더에서 `python3 -m http.server 8000` 을 실행하고 http://localhost:8000 으로 엽니다. (`index.html` 을 바로 열면 브라우저가 처방 파일 자동 읽기를 막습니다.)

## 들어 있는 것

- `index.html` · `style.css` · `app.js` · `clean.js` — 정리기 화면
- `lib/` — SheetJS 0.18.5 (Apache-2.0, `lib/LICENSE`)
- `rules/` — 처방 파일
- `data/출장비정산.xlsx` — 연습용으로 지어낸 엑셀
